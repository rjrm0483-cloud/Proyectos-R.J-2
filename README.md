# Proyectos-R.J-2

Sitio público de RJRM Apps (GitHub Pages). El código fuente completo vive en el repositorio privado `Proyectos-RJ-.`.

- `/` — Política de privacidad de Agenda Psiquiátrica Pro
- `/solar/` — App web Sola FV Pro (se abre en el navegador; en iPhone: Safari → Compartir → "Agregar a pantalla de inicio")

Para actualizar la app solar: copiar aquí el contenido de `sola-fv-pro/www` del repo privado y subir el número de `VERSION` en `solar/sw.js`.
